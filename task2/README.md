# Task 2 - Student Career Progress Dashboard
Figma file: https://www.figma.com/design/EoUQ96FDFj3tXFwlnbgcRY/Student-Career-Progress-Dashboard

1. Overview

Pathway – Student Hub is a responsive dashboard that helps students see their career progress in one place: completed projects, certificates earned, skills developed and upcoming goals.

2. The Task

Students need a dashboard that shows completed projects, certificates, skills earned and upcoming goals. The design should focus on progress clarity and motivation, work on desktop and mobile, include data visualization, and give the student actionable next steps.

3. The Problem

Students collect projects, certificates and skills over time, but this information is usually spread across many places. This makes it hard to see how far they have come and what to do next, which can reduce motivation.

4. Goals
Show progress at a glance, so the dashboard is easy to scan.
Make the numbers meaningful, not decorative.
Keep the screen motivating, with a clear next step.
Work well on both desktop and mobile.
5. Design Decisions
Clear hierarchy

The page starts with a greeting and a short description. Three large metric cards come first (projects, certificates, skills), because they answer the most important question: "How am I doing?". Details such as charts and lists come after.

Meaningful metrics

Each metric has a big number and a supporting detail that explains it, for example "6 of 8" with "75% of your project plan". This tells the student what the number means.

Reusable metric card

I built one metric card (label, number, supporting detail) and reused it for every metric, so the dashboard looks consistent.

Metric card component

Data visualization
A bar chart shows completed projects by month, with a short sentence that explains the trend.
Progress bars show skill levels (technical skills, communication, problem solving) with percentages.
Status labels

Projects, certificates and goals use short word labels (Completed, In progress, Earned, Next up, Planned). Status is shown with words as well as colour, so it does not depend on colour alone.

Actionable next step

A highlighted card, "Finish your portfolio case study", with a Continue goal button, tells the student exactly what to do next. This supports motivation and keeps the dashboard useful.

Colour and typography

A calm blue is used for main actions and the active menu item. Green shows positive progress, and orange and purple mark in-progress and planned items. A clean sans-serif font with clear size differences keeps the text easy to read.

6. Responsive Design
Desktop
A sidebar navigation (Overview, Projects, Certificates, Skills, Goals).
Three metric cards in one row.
Two-column sections for activity, projects, skills, certificates and goals.
Mobile
One-column layout with the same card order, so the experience feels familiar.
A bottom navigation bar (Overview, Projects, Skills, Goals), which is easy to reach with a thumb.
Cards are full width and easy to read on a small screen.

8. What I Learned
A dashboard works best when the most important numbers come first and every number has a short explanation.
Reusing one component, like the metric card, keeps a design consistent and saves time.
Designing mobile and desktop together helps keep the same priorities on both screens.
