**Intern:** Shahd Wael Mohamed Adel
**Program:** UneeQ Interns 2026 – UI/UX Design Track (Batch 35)

## Project
**FoodGo** is a food delivery app (mobile and desktop).

- **Problem:** users get lost between choosing food and paying, so many do not finish their order.
- **Main task:** order a meal and pay.
- **Goal:** create a clear user journey and low-fidelity wireframes that fix this problem.

## Figma File
https://www.figma.com/design/26Q0qqvrcGzweWNFq3HR5U/UneeQ---User-Flow---Wireframing---Shahd-Wael

## What is inside
1. **Information architecture:** 4 main sections (Home, Orders, Cart, Profile).
2. **User flow:** from opening the app to order confirmation, with decision points for login, empty cart, missing details and failed payment.
3. **Mobile wireframes:** 7 screens (home, menu, cart and checkout, loading, error, empty cart, order confirmation).
4. **Desktop wireframes:** menu with the cart beside it, and a one-page checkout.
5. **Key design decisions:** fewer steps, one main button per screen, and clear states.
